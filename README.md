Titanic Dataset - Exploratory Data Analysis (EDA)
Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to understand the factors that affected passenger survival during the sinking of the RMS Titanic sinking.

Using Python, the dataset is analyzed to uncover patterns, trends, and relationships between variables such as age, gender, class, and survival.

Objectives

Understand the structure of the dataset

Handle missing values

Perform statistical analysis

Visualize important patterns and relationships

Identify factors that influenced passenger survival

Dataset

The dataset contains information about passengers on the RMS Titanic, including:

PassengerId

Name

Age

Sex

Passenger Class (Pclass)

Fare

Embarked

Survival status

Technologies Used

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

Steps Performed in Analysis

Data loading and inspection

Data cleaning and handling missing values

Statistical summary of the dataset

Univariate analysis (distribution of single variables)

Bivariate analysis (relationship between variables)

Data visualization using graphs and charts

Key Insights

Female passengers had a higher survival rate than male passengers.

Passengers in higher classes had better chances of survival.

Age and fare also influenced survival probability.

Many missing values were found in the Age and Cabin columns.

Visualizations Included

Survival count plots

Age distribution histogram

Survival by gender

Survival by passenger class

Heatmap for correlation analysis

Conclusion

Exploratory Data Analysis helped identify important relationships in the Titanic dataset. These insights can further be used for building predictive models in machine learning to predict passenger survival.
